Technical walkthrough · Tokyo Airbnb analyst

How the Tokyo Airbnb analyst was built, phase by phase

At a glance
  1. 1 · WhatAn analytics and AI app for the Tokyo Airbnb market: dashboards, maps, a chat agent and search over guest reviews.
  2. 2 · WhyHosts and analysts want prices, gaps and guest sentiment by neighbourhood without writing queries.
  3. 3 · WhoUsers: hosts, investors and market analysts.
  4. 4 · WhereResults page and technical walkthrough on GitHub Pages.
  5. 5 · When it failsA hallucination suite asks the live agent 6 questions and checks each number against the data: 0 hallucinations in the recorded run.
  6. 6 · HowLangChain agent with 7 tools over the listings; retrieval over 25,000 embedded reviews (ChromaDB); TextBlob sentiment; K-Means areas.
Skills applied, with proof
  • GenAI and agents tool-using LangChain agent, retrieval over reviews, AI-guided data merge agent.py rag_agent.py discovery_agent.py
  • Analytics and ML EDA, K-Means geospatial clusters, review sentiment eda.py clustering.py
  • Evaluation hallucination test suite with a written checklist test_hallucination.py checklist
  • CI GitHub Actions lint, unit and browser tests; Pages deploy only after they pass ci.yml
