# ADR-007: Technology Assessment — Small Open Models, Serving and Retrieval

**Status:** Accepted (2026-11-11), before the P7–P11 runs
**Date:** 2026-11-11
**Deciders:** Sabrina Pribadi

---

## Context and Problem Statement

- Rule R21: rate current technology as adopt, trial or hold, each tied to a project question, with cost and free-tier fit.
- **Questions:** (1) Can a small open model, fine-tuned with LoRA and served by vLLM, answer review questions as well as an API model, cheaper and fast enough? (2) Is the current review retrieval good enough?
- **Constraints:** zero cost (R20); development Mac has 8 GB RAM and no NVIDIA GPU; OpenAI spend capped at $5 for this work.
- Licences checked on Hugging Face (2026-11-11); only Apache-2.0 or MIT models qualify (R1; no clauses tied to the user's employer).

## Self-hosted cost reference

- Azure retail price API, Standard_NC4as_T4_v3 (one T4), East US, Linux: **$0.526 per hour** on demand, $0.164 spot (read 2026-11-11).
- Cost per 1,000 answers = hourly price × hours for 1,000 answers at the measured throughput ÷ utilisation (ADR-009).

## Consequences

- **Positive:** every adopted tool is free or within the $5 cap; licences are clean.
- **Negative:** the live app cannot host the small model for free; its value is shown by the benchmark and an offline option.
