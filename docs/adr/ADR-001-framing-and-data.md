# ADR-001: Framing and Data — One Tokyo Snapshot from Inside Airbnb

**Status:** Accepted — written retrospectively on 2026-11-11 from the code and PRD; the decision dates from June 2026
**Date:** 2026-11-11
**Deciders:** Sabrina Pribadi

---

## Context and Problem Statement

- Hosts, investors and analysts ask simple market questions (prices, gaps, sentiment by area) but cannot write queries.
- **Question:** can one public snapshot of Tokyo listings and reviews answer those questions reliably, in plain language?

## Decision Drivers

- Public data only (R1), with a licence that allows reuse.
- Enough reviews for search and sentiment; small enough to run on a laptop.

## Decision

- **Source:** Inside Airbnb, Tokyo, scraped 29–30 September 2025 (CC BY 4.0).
- **Tables:** 27,945 listings; 444,182 reviews from the last 2 years; 10.2 million calendar rows.
- **Processing:** prices cleaned to yen; HTML stripped from reviews; features `price_category` and `listing_score`; saved as Parquet (`scripts/save_processed_data.py`).
- **Pages show aggregates only;** host and reviewer names never leave the data files.

## Considered Options

| Option | Status | Why |
|---|---|---|
| **One Tokyo snapshot** | **Chosen** | Answers the questions; reproducible |
| Several cities | Not now | Same pipeline; more to validate |
| Several snapshots over time | Not now | Needed for trends; one snapshot cannot show change |

## Consequences

- **Positive:** every answer can be checked against one fixed dataset.
- **Negative:** no trend over time; prices are listed prices, not paid prices.
