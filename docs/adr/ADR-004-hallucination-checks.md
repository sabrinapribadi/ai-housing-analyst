# ADR-004: Hallucination Checks against the Data

**Status:** Accepted — written retrospectively on 2026-11-11 from the code and PRD; the decision dates from June 2026
**Date:** 2026-11-11
**Deciders:** Sabrina Pribadi

---

## Context and Problem Statement

- A data assistant that invents numbers is worse than none.
- **Question:** how do we catch answers that contradict the data?

## Decision

- `tests/test_hallucination.py` asks the live agent 6 fixed questions (average price, most expensive and cheapest neighbourhood, listing count, price distribution, most common room type).
- It compares the reported average price with the Parquet ground truth (more than 10% off is an error; more than 20% is high severity) and flags fabricated facts.
- **Recorded run:** 6 questions, 0 hallucinations detected (README).
- It needs an OpenAI key, so it runs locally; CI runs the clustering unit test instead.

## Consequences

- **Positive:** a repeatable check against fixed ground truth.
- **Negative (stated):** only one numeric check (average price) is automated; 6 questions are a small set; the run is manual; cost and latency are not measured (R13 gap).

## Considered Options

| Option | Status | Why |
|---|---|---|
| **Fixed questions vs Parquet ground truth** | **Chosen** | Cheap, exact for the numbers it checks |
| Model-graded answers | Not now | Needs its own validation |
| A larger labelled question set | Next | Would cover every tool and number |
